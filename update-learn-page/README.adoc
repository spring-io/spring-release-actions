= Update Learn Page Action

This GitHub action updates the #learn page on Spring OSS and Commercial Websites.

With a `website-token`, `project/{project}/documentation.json` is edited directly in the website repository, which is how the commercial website is updated.
Without one (OSS only), the Spring Projects REST API is updated instead.

== Inputs

|===
| Input | Description | Required

| `version`
| The current version.
| `true`

| `website-token`
| The GitHub token needed to directly edit spring-website-content or spring-website-commercial-content. Required for a commercial project, for which the action fails without it. When omitted, the Spring Projects REST API is used instead (OSS only).
| `false`

| `release-channel`
| The release channel underway: `oss`, `internal`, `lts`, or `hotfix` (see link:../compute-release-channel[compute-release-channel]). Anything but `oss` selects the commercial website. When omitted, a project name containing `commercial` selects it.
| `false`

| `api-doc-url`
| The URL to the project's JavaDoc; supports `+{version}+` and `+{major.minor}+` placeholders. Defaults to `+https://docs.spring.io/{project}/reference/{version}/api/java/index.html+` if `is-antora` is true (or `+https://docs.enterprise.spring.io/{project}/reference/{major.minor}/api/java/index.html+` for a commercial project), and `+https://docs.spring.io/{project}/site/docs/{version}/api/+` otherwise.
| `false`

| `is-antora`
| Whether the reference documentation is Antora-based; defaults to true.
| `false`

| `project-name`
| The project name (for example, spring-security); will use repo name if not provided.
| `false`

| `ref-doc-url`
| The URL to the project's reference documentation; supports `+{version}+` and `+{major.minor}+` placeholders. Defaults to `+https://docs.spring.io/{project}/reference/{version}/index.html+`, or `+https://docs.enterprise.spring.io/{project}/reference/{major.minor}/index.html+` for a commercial project.
| `false`

| `website-repository`
| The Spring Website GitHub repo to edit; defaults to `spring-io/spring-website-content`, or `spring-io/spring-website-commercial-content` for a commercial project.
| `false`
|===

== Commercial Documentation URLs

The enterprise website doesn't redirect, so a `+{version}+` placeholder can't be left in its URLs for the website to fill in.
Instead, use `+{major.minor}+`, which is replaced with the exact values of each entry's version, so `7.0.6.1` links to `+https://docs.enterprise.spring.io/spring-security/reference/7.0/index.html+`.
This is what the commercial defaults do, and commercial entries are written without an `antora` flag.

The newest generation listed in `documentation.json` is the exception: the website serves it without its `+{major.minor}+` directory (`+https://docs.enterprise.spring.io/spring-security/reference/index.html+`).
So the entries of the newest generation are written without the directory, and when a release starts a newer generation, the entries of the generation it replaces get their directory back.
URLs that were set by hand, outside `/reference/`, are left as they are.

== Example Usage

[source,yaml]
----
- name: Update Learn Page
  uses: spring-io/spring-release-actions/update-learn-page@a1f321783a0769dd2aea4fad6c2ae2f95a52b885 # 0.0.5
  with:
    version: '1.2.3'
    website-token: ${{ secrets.WEBSITE_TOKEN }}
----
